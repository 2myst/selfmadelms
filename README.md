# База дизайна: мини-LMS

Программа по композиции, типографике и цвету с трекингом прогресса.

- `/`: прогресс ученика по всем блокам.
- `/b/<блок>`: материалы блока, статусы заданий, сдача работ, скачивание .md.
- `/manage`: панель ментора (вход по паролю). Здесь выставляются оценки 0/1/2, пишутся комментарии, запускается новая попытка.
- `/download`: все материалы одним zip.

## Как устроено

Источник правды — файлы в `content/`. Задания и критерии сайт берёт прямо из них:
- задание: заголовок вида `## 1.1. Название`;
- критерии: таблица, первая колонка которой называется `Критерий`, а дальше колонки 0 / 1 / 2;
- задание без таблицы (как 3.1) превращается в чекбокс «Выполнено»;
- файл без заданий (readme, литература) становится обычной страницей.

Чтобы поменять программу, отредактируйте .md и запушьте. Сайт пересоберётся сам.

Оценки привязаны к тексту критерия. Если переименовать критерий, оценка по нему сбросится.

Правило зачёта: нет нулей и сумма не меньше 70% от максимума (`lib/grading.ts`, `PASS_RATIO`).

## Запуск локально

```bash
npm install
cp .env.example .env.local   # впишите ADMIN_PASSWORD
npm run dev
```

Откройте http://localhost:3000. Локально без Redis прогресс хранится в `.data/state.json`.

## Деплой на Vercel

1. Создайте репозиторий на GitHub и запушьте проект:
   ```bash
   git init && git add . && git commit -m "init"
   git remote add origin <url репозитория>
   git push -u origin main
   ```
2. На vercel.com: **Add New → Project**, выберите репозиторий, нажмите **Deploy**.
3. В проекте откройте **Storage → Create Database → Upstash (Redis)**, бесплатный тариф, и подключите базу к проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами.
4. **Settings → Environment Variables:** добавьте `ADMIN_PASSWORD`.
5. **Deployments → Redeploy**, чтобы подхватились переменные.

## Про доступ

Страницы ученика открыты всем, у кого есть ссылка. Сдать работу тоже может любой, кто знает ссылку. Для одного ученика это нормально, но не публикуйте ссылку широко. Оценки и комментарии меняются только через `/manage` с паролем.
