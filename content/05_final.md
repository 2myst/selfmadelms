# Финал. Синтез (1–2 недели)

## Задание

1. **Редизайн.** Взять 2–3 свои старые карточки для маркетплейса (Ozon, WB) и переделать их с учётом всех трёх блоков.
2. **Новый экран.** Сделать экран карточки товара в мобильном приложении, условно «своего» маркетплейса.
3. **Документ с обоснованием** (1–2 страницы):
   - сетка и базовый шаг;
   - шкала кеглей, выбор шрифтов;
   - палитра и проверка контрастов;
   - задуманный порядок чтения;
   - скриншоты blur-теста и ч/б-теста.
4. **Разбор «до / после»:** что конкретно было не так в старых карточках, с терминами.

## Критерии

| Критерий | 0 | 1 | 2 |
|---|---|---|---|
| Сетка: 100% элементов на сетке, отступы кратны шагу | много нарушений | 1–2 нарушения | чисто |
| Типографика: единая шкала, не больше 2 гарнитур, 0 типографских ошибок | нарушения | мелкие | чисто |
| Контраст WCAG AA | много провалов | 1 провал | 0 провалов |
| Blur-тест совпадает с задуманным порядком чтения | нет | частично | да |
| Ч/б-тест | разваливается | частично | держится |
| Документ с обоснованием | нет или «потому что красиво» | частично с терминами | каждое решение обосновано |
| Разбор «до / после» | общие слова | часть проблем названа | конкретные проблемы с терминами |

**Итог:** максимум 14 баллов. Работа засчитывается при 10+ баллах и отсутствии нулей.

## Примечание для ментора

Самый показательный пункт здесь — разбор «до / после». По нему видно, начал ли ученик сам видеть проблемы в работе или только повторяет правила из программы.
