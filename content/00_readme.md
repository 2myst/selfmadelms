# Программа: база графического дизайна для старта в продуктовый дизайн

Длительность: 6–8 недель. Блоки: композиция, типографика, цвет, финальный синтез.

Задания не ведут за руку. В каждом есть пункт «Найти самому»: эту теорию ученик ищет и разбирает сам, это часть задания.

## Как оцениваем

Оценка складывается из трёх типов проверок.

**1. Объективные проверки.** То, что можно посчитать: коэффициент контраста, привязка к сетке, число шрифтов, кеглей и цветов, длина строки, типографские ошибки.

**2. Тесты восприятия.**
- *Blur-тест:* размыть макет на 8–10 px. Иерархия должна читаться.
- *Ч/б-тест:* перевести в grayscale. Структура должна держаться без цвета.
- *5-секундный тест:* показать макет 3 людям на 5 секунд и спросить, что они запомнили.

**3. Защита решений.** Каждое решение объясняется одним предложением с термином. Пример: «Сместил вес вправо, чтобы уравновесить заголовок, это асимметричный баланс». Если решение нельзя объяснить, оно считается случайным, даже когда выглядит хорошо.

## Шкала

Каждый критерий оценивается так:
- **0**: не выполнено;
- **1**: частично;
- **2**: выполнено.

Задание засчитывается, если нет ни одного нуля и сумма баллов не меньше 70% от максимума.

Если задание не прошло, ученик переделывает его один раз, после разбора с ментором.

## Шаблон сдачи задания

Каждое задание сдаётся в одном формате:
1. Макеты: ссылка на Figma или экспорт.
2. Для каждого макета 1–3 предложения защиты решений с терминами.
3. Скриншоты тестов, если задание их требует: blur, ч/б, контраст.
4. Что было непонятно и где искал информацию.
